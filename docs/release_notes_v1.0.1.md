# MedTracker v1.0.1 — Release Notes

## 🚀 Что нового в версии 1.0.1

### 🎨 Улучшения интерфейса и UX
- **Удалена отдельная вкладка «Курсы»**: Управление курсами приёма теперь нативно встроено в карточки лекарств и модальные окна создания/редактирования. Навигация оптимизирована до 4 понятных разделов: **«Сегодня»**, **«Лекарства»**, **«Медкарта»**, **«Настройки»**.
- **Оптимизация мобильной оболочки (Android)**:
  - Скорректированы отступы нижней навигационной панели под системный жест «домой» (gesture pill) — текст больше не перекрывается.
  - Добавлен перенос длинных строк (`TextWrapping="Wrap"`) на экранах авторизации, настроек и списка лекарств.
  - Пикер количества приёмов переведён на `WrapPanel` — все кнопки (1–6) отображаются аккуратно на экранах любых размеров.
  - Исправлены отображение тумблеров и рендеринг текста в пустых состояниях (`EmptyState`).

### 📱 Android
- Устранена ошибка инициализации рантайма Avalonia на Android (`UnsatisfiedLinkError: n_onCreate` в `MedAndroidApplication`).
- Проверена стабильная работа всех экранов и переходов на Android AVD / физических устройствах.
- Сформирован свежий подписанный релизный пакет `MedTracker-1.0.1.apk` (71 МБ).

### 🍏 macOS
- Сформирован релизный DMG образ `MedTracker-1.0.1.dmg` (54 МБ) с нативным `.app` бандлом.
- Добавлен автоматизированный скрипт установки `install.sh`, исключающий блокировки Gatekeeper/карантина:
  ```bash
  curl -sSL https://raw.githubusercontent.com/Mysechka/MedTracker/main/install.sh | bash
  ```

### ⚙️ Стабильность и архитектура
- 273 теста пройдены успешно (100% pass rate).
- Улучшена локальная синхронизация доз и событий приёма лекарств в SQLite.
- Полное соблюдение Clean Architecture (нулевые внешние зависимости в доменном слое).
