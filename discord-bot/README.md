# MedTracker Discord Bot

Discord-бот для системы MedTracker. Предоставляет возможность привязки каналов Discord к аккаунтам пользователей через 6-значный одноразовый код (`/link <код>`) и отправки уведомлений о приёме лекарств.

## Возможности
- Чтение параметров и токенов из корневого `.env` файла.
- Регистрация и обработка слэш-команд:
  - `/ping` — проверка доступности и задержки бота.
  - `/link <code>` — привязка Discord-канала к профилю MedTracker по 6-значному коду.
- Обработка префиксных команд:
  - `!ping` — проверка статуса.
  - `!link <код>` — текстовая привязка.
- Интеграция с Supabase RPC (`confirm_messenger_link`).
- Сервис рассылки напоминаний в привязанные каналы.

## Запуск
1. Убедитесь, что в файле `.env` в корне репозитория заданы:
   ```env
   DISCORD_BOT_TOKEN=ваш_токен_бота
   DISCORD_APPLICATION_ID=ваш_id_приложения
   SUPABASE_URL=https://<project-ref>.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=ваш_service_role_key
   ```
2. Установка зависимостей:
   ```bash
   npm install
   ```
3. Запуск тестов:
   ```bash
   npm test
   ```
4. Запуск бота:
   ```bash
   npm start
   ```
