# MedTracker v1.0.0 — Release Notes

## ✅ Доступно и работает стабильно

- Управление лекарствами: добавление, редактирование, удаление
- Курсы приёма: создание расписаний с гибкой настройкой (N раз/день, через N дней, дни недели)
- Экран "Сегодня": отображение текущего расписания приёмов с отметкой о приёме
- Медкарта: хранение документов и медицинских файлов
- Профиль: настройка часового пояса (смещение от Москвы)
- Локальные уведомления о приёме лекарств (macOS + Android)
- Авторизация через Supabase Auth (email/password)
- Clean Architecture: полное разделение слоёв
- Поддержка macOS и Android
- Автосборка через CI/CD (GitHub Actions)

## 🔧 В доработке (не включено в релиз / отключено)

- Discord-бот: уведомления через Discord (требует настройки Interactions Endpoint)
- Telegram-бот: уведомления через Telegram webhook
- Edge Functions (tick, telegram-webhook, discord-interactions): серверная логика для мессенджеров
- Облачная синхронизация расписаний в реальном времени (Supabase Realtime)

## ⚠️ Работает, но может быть нестабильно

- Realtime-подписки: экран диагностики Realtime присутствует, но поведение зависит от состояния Supabase-инстанса
- Загрузка медицинских файлов: зависит от настройки Storage bucket в Supabase
- Расписание при смене часового пояса: пересчитывается, но edge-кейсы при частой смене возможны
- Android: первый запуск может занимать до 5-7 секунд на старых устройствах
